data/ai4i2020.csv in this folder was GENERATED by scripts/make_dataset.py
because the UCI download was unreachable.

It follows the failure rules published with the AI4I 2020 dataset, so
failure prevalence and the mix of failure modes are representative, but
it is NOT the real dataset. For a submission that claims real data, delete
this file and data/ai4i2020.csv, then re-run with internet access:
  https://archive.ics.uci.edu/static/public/601/ai4i+2020+predictive+maintenance+dataset.zip
